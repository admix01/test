# Sources et licences

## DadaGP

Dépôt : `https://github.com/adhooge/guitar-chord-diagram-suggestion`

Données incluses sous ODbL 1.0 :
- `dadagp_positions_flat.json` (ex-`DadaGP-chords.csv`)
- `dadagp_positions_normalized.csv` (ex-`DadaGP-chord_pairs_unique.csv`)

Licence complète : `LICENSE_DadaGP_ODbL.txt`

## Tombatossals chords-db

Dépôt complémentaire recommandé : `https://github.com/tombatossals/chords-db`

JSON officiel : `https://github.com/tombatossals/chords-db/blob/master/lib/guitar.json`

Licence MIT incluse : `LICENSE_tombatossals_MIT.txt`

Le JSON officiel n’est pas recopié dans ce pack. Le pack contient à la place une base DadaGP agrégée et directement exploitable. Tombatossals reste utile pour récupérer les doigtés de doigts et les barrés.

## Triads de makaroni4

Dépôt de comparaison : `https://github.com/makaroni4/triads`

Licence MIT incluse : `LICENSE_triads_MIT.txt`

Les triades fournies dans ce pack ont été recalculées à partir de l’accordage standard et des formules d’intervalles.
